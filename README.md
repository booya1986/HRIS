# HRIS unit research report

Standalone HTML version of a verified-research report (Hebrew, RTL): what an HRIS function is, how it is set up globally and in Israel, three evolving structures for a new HRIS + HR-data unit, the weight of the data function, creating real value with AI, a KPI framework, and blind spots for a leader coming from L&D.

- `index.html` is the published page (GitHub Pages).
- `build.py` + `components.py` + `template.html` rebuild it from the source note in the Obsidian vault.

Generic by design: no employer names, internal systems or people.
